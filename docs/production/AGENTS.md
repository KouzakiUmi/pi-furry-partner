# Umi 角色制作工作流（本目录及子目录）

开始任何生图、H3、设定图、漫画或 PV 制作前，必须读本目录的 [PRODUCTION-SPEC.md](PRODUCTION-SPEC.md)、turnaround-STATUS.json，以及本轮 review.json。先核对用户最新反馈；规范不覆盖用户后续纠正。

最新用户授权2026-10-22：“先全部做完吧 不要一段段了”。当前视频改为整片完成后一次评审；下文逐镜等待用户再扩展的旧规则在本轮不适用。两路实际内部校对、原设定/色卡约束、源历史和必要重做继续执行。

- 每轮实际安排两路独立子代理看图：A 查颜色/材质/纹样；B 查空间/解剖/全身一致性。沿用用户指定的 6.1 Sol high 规格；不得用主代理自检冒充两路检查，不得只复用旧轮次报告。
- 先比较原二维设定、已认可且适用于本部位的素材和当前所有对应视图，再写提示词。只在新旧候选之间比较是不够的。
- 用户认可按部位、用途记录，不能将“斗篷/爪形过了”扩张成“尾巴颜色也通过”。2026-10-22 正面 v6、背面 v4 的尾巴颜色均已被用户否决。
- 图像艺术修正整张重新生成，保留参照和失败历史。不得擅自局部画改、脚本染色、拼接修图；用户明确同意的特定例外只对该次范围生效。
- 同一问题连续两次未达到目标，停止同提示小改循环；查参照、收窄试点或改变工作方法，再交用户评审。
- “改善了”不是“通过了”；未决问题、不可见结构、仅供配色核对的平涂稿都要明说。用户未评审不得扩展下一批或安装发布。
- 不要在本任务中改写已认可侧视及已批准动作。先完成设定图，再恢复相关视频生产。
