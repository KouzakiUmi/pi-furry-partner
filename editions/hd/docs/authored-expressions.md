# HD 定稿表情

[小动作与时长](shared-gesture-modules.md) · [HD 指南](guide.zh-CN.md) · [制作历史](h3-expression-videos.md)

当前 HD catalog 含 29 个已批准完整片段，其中九种表情与八个辅助动作共同组成 /mascot action 的 17 项目录。九种表情当前各为 4458ms，按批准帧与真实时钟播放；不是仍待接入的静态候选，也不代表本轮重新安装或发布了 HD。

| ID | 含义 | Pi HD 使用 |
| --- | --- | --- |

| grumpy | 叉腰鼓脸 | 手动选择 |
| sad | 委屈 | 手动选择 |

用 action shy 单次、action all 循环、action off 停止；Tab 与菜单从本目录元数据生成。是否自动出现还受真实任务、可见性、开关、活动状态与优先级约束，不将表情当作工具已完成的证据。

历史九格、静态批准、撤回批次及颜色修正的原始证据保留在 Hi-Res 和 assets/animated/provenance。不能用早期候选的批准冒充后续造型或整套配色通过。DSH 抚摸／陪伴入口由独立仓库维护，不属于 Pi 插件命令。
