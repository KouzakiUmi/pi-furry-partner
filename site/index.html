A FEW THINGS TO KNOW

出发前，
再说两句。

需要什么环境？+

面向桌面端 Pi 交互 TUI，当前原生中文与提示词适配以 Pi 1.2.0 为基准。需要 Node.js 22.19.0 或更新版本，当前已在 Node.js 24 环境验证。高清角色需要支持 Sixel 的终端；不支持时可切换为字符块渲染。Windows 可使用支持 Sixel 的新版 Windows Terminal。

会改变代码、工具输出或项目规则吗？+

界面中文化只处理识别过的固定界面文字。代码、命令、工具输出和模型回答保持原文。文档提示精简独立开关，自定义 SYSTEM.md、项目 AGENTS.md、技能及工具规则保留。角色口吻只在你开启时参与下一轮提示词。

动画和网页会额外调用模型吗？+

动画根据本地 agent 事件切换，不为表情发起模型请求。本页演示在浏览器本地运行，不发送聊天内容，也不连接你的 Pi 会话。

为什么有时是快捷键，有时可以点击？+

插件跟随 Pi 当前 TUI 模式：fullscreen 模式保留鼠标快捷操作；regular 模式显示与实际键位对应的快捷键提示。两种模式都可用 Ctrl+Alt+W 打开更多功能。

代码开源，角色也能随意使用吗？+

代码和文档采用 Apache-2.0。呜咪的角色设计、原图及动画素材单独保留全部版权，不受代码许可证授权。请不要把这些素材视为自由商用或可再授权素材。具体范围请查看仓库的素材许可文件。
