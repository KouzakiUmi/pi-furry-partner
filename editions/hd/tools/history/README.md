# Historical migration tools

These are records of one-time migrations. Their old absolute paths describe
past worktrees; they are not active build or asset-rebuild entry points.

Paths below are relative to `editions/hd/` on main. DSH is maintained in its separate repository; historical combined-platform recipes are not current commands.

Use `tools/build-editions.py` to build current products, and
`scripts/restore_header_timeline.py` to verify or restore accepted title banks.
Do not run historical migrations over the consolidated source tree.
