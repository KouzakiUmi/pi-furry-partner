# Character assets

Read `../docs/production/AGENTS.md` and `../docs/production/PRODUCTION-SPEC.md` before artwork changes. The current user instruction takes precedence over archived production notes.

Keep original 2D material cards authoritative, keep shadows separate from base colors, retain user review gates, and use the two independent visual reviewers required by the production spec. Do not change approved movement or anatomy when fixing only color.

Current reusable evidence is in `production/`, `approved-static-20261018/`, and `../assets/animated/provenance/`. The original long-running notes are retained as `../docs/production/HISTORICAL-20261018.md`; expired pauses, per-job authorizations and temporary paths in that snapshot are historical, not current workflow instructions.
