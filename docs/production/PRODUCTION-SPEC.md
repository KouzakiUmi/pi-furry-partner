## 2. 底色与阴影（先后分验）
原色卡是局部材质底色依据，不能从明暗面或生成稿取样新增毛色。
- 白 #FFFFFF；肉垫/耳内粉 #FFC8C3；围巾浅蓝 #89B4E7。
- 主灰 #A6A6A6；深灰 #858585。尾巴原独立示意明确支持浅灰中段和深灰末段，不可将正确深灰分区当阴影删除。
- 蓝灰 #506175；深蓝灰 #3B4857。阴影不能把蓝灰兜帽/斗篷改成全黑或使画面绿、青、紫、棕污染。
- 各视图及穿衣/无衣版共用同一身体材质与固有色块，服装遮挡与光照不改变毛色。

## 3. 耳朵与透视
- 保持同一只折耳/立耳的角色身份。以用户批准旋转追踪耳根、体积、遮挡；前后转身后画面左右变化。
- 用户确认鼻向右近侧折耳；鼻向左近侧立耳是保持耳朵身份后的对应技术解释。不得把深度遮挡变成耳根前后错位。
- 上约 1/3 向前（鼻方向）折约 90°；下 2/3 保有体积。硬布、钝尖、近似半圆锥体：正面近三角，下部微凸、上部趋平，背面有弧面体积，不是平叶、凹袋或薄片。
- X 在面片接缝处随折角包转，是两条交叉线，不能变星星、雪花、A、三角环。可见针数对照使用版本，不推定隐藏总数。
- 背帽缝线路径依原二维后视；不要凭空添加耳根环带、竖排装饰或多余接片。

## 4. 服装、身体与爪
- 斗篷是一层连续主体、一条下摆。领肩到侧缘到下摆要跨视图相符；禁止腕旁短披片、额外白边、第二层裙片。褶皱是连续布面变形。
- 一条围巾恰好两条自由末端。新高清围巾标记是小型六臂分叉雪花，不是加号/星星；旧成品不回溯批改。
- 四趾是解剖结构，不是每个角度必须数到四枚可见爪。短爪接对应趾端；遮挡应合理，不能补悬空爪、后跟爪排或第二排粉色肉指。
- 前爪掌体、腕部、短圆趾连续；掌面四趾垫加一个中央肉垫，beans 形状按原图，不把“改肉垫”扩成改整个手掌。
- 背视肉球专项：中央掌垫依原 paw-anatomy 为宽而圆润分叶的一整块，不是长椭圆/水滴。小趾垫贴趾腹并由灰毛分隔，避免挤成突出肉指串；随当前下垂掌面透视，不为展示肉垫转动/张开整个爪子。用户新指出此项未通过，侧视候选先保留，不越过这一轮评审。
- 肉垫不止验收轮廓：必须核对腕→掌垫→趾垫→爪尖的落点、中央垫凹凸朝向与左右手对应。back-paw-v1 虽改成分叶仍被用户退回“肉垫方向关系不对”；不能把分叶改善当作方向正确。旋转源图仅作方向检查，不拼贴生产图。
- 用户已明确本次方向问题：“歪了，和胳膊的方向不匹配”。修正肉垫整组相对前臂/手腕的局部旋向，让掌垫与趾垫顺着同一条腕掌轴线，逐只爪看投影；不是把全部肉垫翻转180°或互换左右手。不得以移动整手、扭腕或改胳膊轮廓来迁就歪肉垫。
- axis-v2/v3 后续被用户指出“手的结构被破坏了”。禁止继续以这些失败手部为基准迭代；回到尾色通过的 back-pair-v7 手结构，逐趾核对趾根、趾腹、爪尖及拇趾遮挡。外轮廓大致没动不等于内部结构保持；肉垫必须服从原有趾腹，不为凑四垫重画四个朝镜头伸出的肉趾。
- 后视脚显示脚跟与后侧，不能贴正面趾排。握拳/叉腰不得被修爪破坏，胳膊不能变细。
- 穿衣/无衣版保持同一骨架、头身、肩宽、腕踝、四肢和尾巴体量；衣物造成的遮挡才是合理差异。无衣版去掉兜帽、斗篷和围巾，展示全毛身体。
- 眼线、豆豆眉、折耳、嘴形、指甲短尖与透视需纳入每次全图检查，不能只检查目标部位。

## 5. 每轮执行及两路子代理
1. 主代理读规范、用户反馈、状态；确定本轮参照职责与批准范围，列出一个明确试点目标。
2. 两路实际独立看图：A 材质/底色/色块/阴影/纹样；B 耳根/体积/遮挡/爪形/全身比例及跨视图对应。继续使用用户指定的 6.1 Sol high 协助规格，避免重复推理。
3. 生图前用原设定和适用已认可参照设计提示词。禁止沿用已撤回的提示词约束。
4. 整张生成，保留源图、提示词、候选和版本。内部可裁切放大检查，不能以裁片替换生产图。
5. 新稿两路均实际复核；主代理汇总：确定错误、不可见/未确认项、审美待用户评项。不得把无新增错误等同全图合格。
6. 内部执行规则（不是用户指定次数）：相同缺陷连续两次失败，停止同式重试；回查参照或用底色/结构试点隔离原因。节省 LLM 反复推理，不用它替代重新生成。
7. 评审页必须直接展示本轮原图、相关原设定、前后视对照与已知问题；评审记录包括参照/输入、提示词、两路报告、技术判断、用户判断，互不冒充。
8. 用户按范围评审后才扩大。用户否决后撤回相应“通过”记录，不保留矛盾的验收结论。不得擅自安装、发布或替换已批准素材。

## 6. 后续动画保留约束（当前不扩展）
- 动画要表现情绪、微表情与全身协调，不是静图扭曲晃动，也不是逐肢体机械分解。
- 连续 H3 动作沿用批准首/尾与中间表演职责；节奏、循环接缝、耳/爪/下摆、色彩、锚点和显示尺度分别检查。
- 抠绿后要检查透明边缘、白边/绿噪与主体颜色；不得把抠色修复等同校色。沿用已授权具体方法，未经同意不扩展局部改画例外。
- 转场速度线等可为独立特效层。普通高清逻辑版与全动态重做版分开；角色印象 PV 与插件中英文宣传片分开。
